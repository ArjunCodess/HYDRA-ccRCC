# Candidate ledger schema

Run `Rscript analysis/39_candidate_ledger.R` from the repository root, then `Rscript analysis/tests/test_candidate_ledger.R`. These commands use the recorded result tables, regenerated by the pipeline for this revision. The generator joins evidence and checks the recorded Cox BH adjustments; it does not refit models.

`results/tables/candidate_ledger.csv` has one row per mapped TCGA symbol representative, including genes that fail discovery differential expression. This universe comes from `reproducible_deg_tcga_gse40435_gse53757.csv`: the mapping rule retains one Ensembl identifier per symbol after sorting by TCGA adjusted DE p-value. Unmapped genes are outside this ledger, and their exclusion is not a validation failure.

The scalar fields record the gene identifier and symbol; primary cohort and model; discovery log fold change and adjusted p-value; primary adjusted Cox log hazard ratio, hazard ratio, 95% interval, nominal and adjusted p-values, sample size and events; effect direction; PH diagnostic; serial selection flags; and final discovery status. Missing numeric estimates are CSV `NA`. Missing assessments are labeled `not_assessed`, not interpreted as a negative finding. Cox estimates are per standardized expression unit. DE and survival effect directions describe different contrasts.

`discovery_de`, `reproducible_de`, `adjusted_survival`, `covariate_sensitivity`, `strict_candidate`, and `priority_shortlist` are nested selection flags using the existing rules and thresholds in `analysis/00_config.R` and `analysis/10_candidate_table.R`. `results/tables/ledger_funnel_counts.csv` records their counts and attrition from the previous stage. PH checks are diagnostic and do not remove candidates. The priority shortlist is an internal discovery classification, not a validated panel.

The JSON columns retain all rows and all fields from each source table, with unavailable estimates encoded as JSON `null`. The object `{"status":"not_assessed"}` means the source table contains no assessment for that gene. JSON preserves cohort-specific effects, uncertainty, multiplicity, covariate adjustment and diagnostic fields without multiplying ledger rows.

External replication, bootstrap uncertainty, conditional held-out prediction, purity and marker adjustment, and HPA cell-source reference evidence annotate the shortlist. They are not sequential selection stages. The `external_replication` scalar summarizes E-MTAB-1980's recorded support, while the cohort JSON columns preserve contradictory GSE29609 evidence. Cell-source evidence comes from normal tissue and does not establish malignant-cell origin. Conditional cross-validation does not remove selection optimism; nested prediction results remain cohort-level artifacts rather than per-gene validation claims.

The counts file also contains rows labeled `annotation_not_serial_gate`. These report external coverage and support, bootstrap intervals, purity and marker retention, and PH flags without defining further attrition. Matched-list procedure comparisons come from `funnel_external_summary.csv`, whose equal-sized lists differ from the complete discovery shortlist. The generator writes their values to `paper/review_macros.tex`, and writes all priority genes and their recorded effects to `paper/review_candidate_table.tex`. Both files are generated inputs for the manuscript.

The test reconstructs selection gates from estimates, checks unique identifiers and nested counts, compares strict and priority gene sets with their source tables, recomputes BH adjustment within each recorded Cox model, validates JSON and checks the manuscript funnel macros in `paper/results_macros.tex`. Optional `paper/ledger_claims.csv` rows declare `macro,stage`; optional `paper/ledger_gene_claims.csv` rows declare `claim,symbol,stage`. Named-gene declarations assert membership of a selection stage. They do not assert external support or clinical utility.

The test also derives all review macros from their source tables, verifies the generated table's complete gene set, checks ACADM's recorded E-MTAB-1980 support, and tests the exact GSE29609 FDR reversal set and marker-adjustment loss set. Changing those scientific claims requires changing the supporting analysis results and reviewing these assertions.
